# hutaao-blog

hutaao 的个人博客，用于整理技术学习、编程实践与研究笔记，也记录日常想法和生活片段。希望把零散的探索整理成可以回顾、交流的内容。

**访问网站：[hutaao.github.io/personal_site](https://hutaao.github.io/personal_site/)**

## 阅读与浏览

首页展示文章列表，点击标题即可阅读全文。文章页提供目录、发布时间、分类、标签、字数和预计阅读时间，方便浏览与定位内容。

- **归档与搜索**：按时间、分类或标签查找文章，也可以通过导航栏的搜索按钮检索内容。
- **动态与相册**：浏览短篇记录和照片，了解文章之外的日常。
- **网址导航与关于**：查看整理的网站链接，以及作者的个人介绍。
- **联系与订阅**：个人资料中的邮件按钮可打开邮件客户端；RSS 和 Atom 可用于订阅文章更新。

## 外观与播放

右上角的调色盘提供外观、壁纸和特效设置，可切换明暗主题、背景模式及动画效果。首页支持全屏壁纸入场，向下滚动后进入文章区域。

音乐可从侧栏或左下角的悬浮播放器手动播放，支持切歌、音量调节、播放列表和同步歌词。悬浮播放器与歌词可分别关闭，再从侧栏音乐板块开启。

导航栏的播放按钮用于播放主页视频。音乐与视频不会同时播放：启动其中一项时，另一项会自动暂停。
